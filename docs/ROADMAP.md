# 창 관리 중심의 개발 계획

KRect는 작업 시작과 전환 때 창을 반복해서 정리하는 수고를 줄인다.
KDE의 패널 작업 영역, 가로·세로 모니터와 전역 단축키에 맞춰 자연스럽게 동작하는 것이 우선이다.

| 순서 | 기능 | 첫 구현의 범위 |
| --- | --- | --- |
| 선행 검증 | Plasma 6 / Wayland 실기 | 배치 막대의 표시·위치·포커스, 배율과 모니터 전환 검증. 현재 로컬 실기는 Plasma 5 / X11이다. |
| 1 · 0.4.0-rc.1 | 반대쪽 창 추천 | 드래그 2분할 뒤 같은 모니터의 열린 창을 선택. 클릭·Enter로 배치, Esc·바깥 클릭으로 건너뛰기. |
| 2 · 개발 중 | 두 창 자리 바꾸기 | 같은 모니터에서 두 창의 위치·크기 교환과 함께 되돌리기. 자동 검사는 통과했으며 실기 검증 뒤 릴리즈한다. |
| 3 | 작업 배치 저장·복원 | 이미 열려 있는 창의 위치·크기를 이름 있는 배치로 저장하고 복원. 앱 실행이나 문서 재열기는 포함하지 않는다. |
| 이후 | 모니터 구성별 배치 기억 | 연결·해제, 가로·세로 방향과 배율 변화에 맞춘 배치 복원. |

About 화면도 0.4.0-rc.1에 포함한다. 각 단계의 실기 검증이 끝나기 전에는
지원이 확인된 것으로 표시하거나 자동으로 릴리즈하지 않는다.

## 캡처 범위

전체 화면·영역 선택·미리보기·편집을 갖춘 캡처 앱으로 확장하지 않는다.
기존 프로토타입은 `experiments/capture/`에 보관하며 앱 메뉴와 Debian 패키지에 포함하지 않는다.
구체적인 필요가 확인되면 **선택한 창을 이미지로 복사**하는 한 동작부터 재검토한다.
