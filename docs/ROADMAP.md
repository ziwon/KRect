# 창 관리 중심의 개발 계획

KRect는 작업 시작과 전환 때 창을 반복해서 정리하는 수고를 줄인다.
KDE의 패널 작업 영역, 가로·세로 모니터와 전역 단축키에 맞춰 자연스럽게 동작하는 것이 우선이다.

| 순서 | 기능 | 첫 구현의 범위 |
| --- | --- | --- |
| 선행 검증 | Plasma 6 / Wayland 실기 | 배치 막대의 표시·위치·포커스, 배율과 모니터 전환 검증. 현재 로컬 실기는 Plasma 5 / X11이다. |
| 1 · 0.4.0-rc.1 | 반대쪽 창 추천 | 드래그 2분할 뒤 같은 모니터의 열린 창을 선택. 클릭·Enter로 배치, Esc·바깥 클릭으로 건너뛰기. |
| 2 · 0.4.0-rc.2 실험적 기능 | 두 창 자리 바꾸기 | 같은 모니터에서 두 창의 위치·크기 교환과 함께 되돌리기. 자동 검사는 통과했으며 실기 검증은 남아 있다. |
| 3 · 0.4.0-rc.2 | 데스크톱별 작업 공간 프리셋 | 각 가상 데스크톱의 앱·창 위치·크기 저장, 수동 및 KRect 시작 시 복원. Plasma 5/X11 듀얼 모니터 복원 검증 완료. 미실행 앱 열기는 선택 사항이며 문서·탭은 앱 자체 세션 복원을 따른다. |
| 이후 | 모니터 구성별 배치 기억 | 연결·해제, 가로·세로 방향과 배율 변화에 맞춘 배치 복원. |

About 화면도 0.4.0-rc.1에 포함한다. 실기 검증이 끝나지 않은 범위는 RC 노트에 명시하고,
지원이 확인된 것으로 표시하거나 안정판으로 올리지 않는다.

작업 공간 프리셋이 다음 주력 기능이다. 예를 들어 D1 개인 개발, D2 학습,
D3 트레이딩, D4 회사 일을 각각 이름 붙여 저장한다. 두 창 교환은 보조 기능으로 유지한다.
실제 재로그인·미실행 앱 열기와 Plasma 6/Wayland 검증은 남아 있으며, 로컬 설치는 RC1을 유지한다.

## 캡처 범위

전체 화면·영역 선택·미리보기·편집을 갖춘 캡처 앱으로 확장하지 않는다.
기존 프로토타입은 `experiments/capture/`에 보관하며 앱 메뉴와 Debian 패키지에 포함하지 않는다.
구체적인 필요가 확인되면 **선택한 창을 이미지로 복사**하는 한 동작부터 재검토한다.
