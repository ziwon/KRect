# KRect 0.3.1

## 한국어

**드래그 배치 막대가 제대로 보이고, 작업 창 위에 유지되도록 수정했습니다.**

### 고친 점

- 앱 이름이 붙은 배치 막대 창도 인식해 모니터 상단 중앙에 정확히 표시합니다.
- 다른 앱을 드래그할 때 KDE가 배치 막대를 보조 창으로 판단해 숨기던 문제를 수정했습니다.
- ‘항상 위’ 창에 가려지지 않도록 막대를 앞으로 올립니다. 작업 창의 포커스와 ‘항상 위’ 설정은 유지합니다.
- 실제 앱과 같은 창 이름·메인 창을 사용하는 검증에 숨김 상태와 창 겹침 순서 확인을 추가했습니다.

### 업데이트

트레이 메뉴에서 **KRect 종료**를 선택한 뒤, Ubuntu 버전에 맞는 `.deb`를 설치하세요.
창의 × 버튼은 앱을 트레이로 숨길 수 있으므로 트레이 메뉴에서 종료해야 합니다.

```bash
sudo apt install ./krect_0.3.1-1ubuntu24.04_all.deb
```

Ubuntu 26.04에서는 해당 파일명으로 바꾸세요. 설치 후 KRect를 다시 실행하고 트레이에 켜두세요.
설치에만 관리자 권한이 필요하며 앱은 일반 사용자 권한으로 실행합니다.
이번 버전에는 개발 중인 스크린샷 캡처 기능이 포함되지 않습니다.

### 검증 범위

자동 테스트 **82개**와 Plasma 5.27 / X11 듀얼 모니터의 **실기 6개 시나리오**를 확인했습니다.
막대 표시와 겹침 순서, 정확한 배치·간격, 포커스 유지, 복원, Esc 취소와 세로 모니터 전환을 검증합니다.
Ubuntu 24.04·26.04 패키지 설치·제거와 Qt 5/6 UI 생성은 릴리즈 CI에서 확인합니다.
**Plasma 6 / Wayland의 실제 드래그·겹침 순서, 혼합 배율과 모니터 연결 변경은 추가 검증이 필요합니다.**
[검증 기록](https://github.com/ziwon/KRect/blob/v0.3.1/docs/VALIDATION.md)

## English

**Fixes the drag-layout bar disappearing or sitting behind your work window.**

### Fixed

- Recognizes the snap bar when Qt appends the application name, so it is positioned at the display's top center.
- Prevents KDE from hiding the bar as an inactive application's utility window while you drag another app.
- Raises the bar above always-on-top work windows while preserving the dragged window's focus and keep-above setting.
- Tests now include the production window title and a main application window, and check native visibility and stacking order.

### Update

Choose **Quit KRect** from the tray before installing the `.deb` for your Ubuntu version.
The window's × button may only hide the app in the tray.

```bash
sudo apt install ./krect_0.3.1-1ubuntu24.04_all.deb
```

On Ubuntu 26.04, substitute the matching filename. Reopen KRect after installation and keep it running in the tray.
Administrator privileges are needed only for installation; run the app as your normal user.
The screenshot-capture prototype is not included in this release.

### Validation

Checked **82 automated tests** and **6 live scenarios** on a Plasma 5.27 / X11 dual-monitor desktop.
Coverage includes bar visibility and stacking, exact placement/gaps, focus preservation, restore, Esc cancellation and portrait transfer.
Release CI checks Ubuntu 24.04/26.04 package installation/removal and Qt 5/6 UI construction.
**Actual Plasma 6 / Wayland dragging and stacking, mixed scaling and monitor hotplug still need validation.**
[Validation record](https://github.com/ziwon/KRect/blob/v0.3.1/docs/VALIDATION.md)
