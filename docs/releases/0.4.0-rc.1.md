# KRect 0.4.0-rc.1

**프리릴리즈 / Prerelease** · 안정판 / Stable: [0.3.1](https://github.com/ziwon/KRect/releases/tag/v0.3.1)

## 한국어

창 하나를 반쪽에 놓은 뒤, 다른 쪽에 놓을 창을 골라 두 창 정리를 끝낼 수 있습니다.
실사용 피드백을 받기 위한 첫 번째 릴리즈 후보입니다.

### 새 기능

- **다른 쪽에 놓을 창 추천:** 상단 배치 막대에서 좌우·상하 반쪽으로 끌어 놓으면 같은 모니터·데스크톱·활동의 열린 창을 보여줍니다.
- 창을 클릭하거나 방향키와 Enter로 고르면 반대쪽에 배치합니다. Esc, 건너뛰기 또는 바깥 클릭은 첫 번째 배치만 유지합니다.
- 최소화·전체 화면·대화상자·제외 앱과 영역에 맞지 않는 창은 추천하지 않습니다. 배치가 거절되면 두 번째 창을 이전 위치로 돌립니다. 각 창의 원래 배치 복원도 지원합니다.
- **앱 정보:** 앱 하단과 트레이에서 버전·웹사이트·GitHub·라이선스를 확인할 수 있습니다.

추천은 드래그 2분할에서만 표시합니다. 단축키·앱 버튼·3분할·4분할에는 나타나지 않으며 환경설정에서 끌 수 있습니다.
캡처 프로토타입은 보류했습니다. 앱과 Debian 패키지에는 포함하지 않습니다.

### 설치와 사용

기존 KRect를 트레이의 **종료**로 완전히 종료한 뒤 설치하고 다시 실행하세요.
Ubuntu 24.04에서는 다음 명령을 사용합니다. 26.04는 아래 표의 해당 파일을 사용하세요.

```bash
sudo apt install ./krect_0.4.0~rc.1-1ubuntu24.04_all.deb
krect
```

Debian 파일명의 `~rc.1`은 정식 0.4.0으로 정상 업그레이드하기 위한 표기입니다.
앱을 켜고 임시 창 두 개로 반쪽 배치, 후보 선택, Esc 건너뛰기와 복원을 확인해 주세요.

### 검증과 제한

- 자동 테스트 **101개** 통과: Node 73개, Python 28개. RC에서 정식 버전으로의 Debian 버전 정렬도 검사합니다.
- Plasma 5.27/X11 실기 **4개 시나리오**: 클릭 배치·포커스·두 창 복원, Enter 선택, Esc 건너뛰기, 바깥 클릭.
- Ubuntu 26.04 / Qt 6.10.2에서 한국어·영어 화면 생성 및 선택창·배치 막대 테스트 9개 통과.

## English

Place one window in a half, then choose another window for the opposite half to
finish arranging the pair. This first release candidate is intended for daily-use feedback.

### New features

- **Second-window suggestions:** dropping into a left/right/top/bottom half on the snap bar offers eligible open windows on the same monitor, desktop and activity.
- Click a candidate or use arrow keys and Enter to place it. Esc, Skip or an outside click keeps only the first placement.
- Minimized, fullscreen, dialog, excluded and size-incompatible windows are omitted. Refused placements restore the second window's previous position. Both windows retain their own restore action.
- **About:** access the version, website, GitHub and license from the footer or tray.

Suggestions appear only after dragging into halves, not for shortcuts, app buttons,
thirds or quarters. They can be disabled in Preferences. The capture prototype is
shelved and is not included in the app or Debian packages.

### Install and try

Quit the existing KRect through its tray menu, install the package, then launch it
again. For Ubuntu 24.04:

```bash
sudo apt install ./krect_0.4.0~rc.1-1ubuntu24.04_all.deb
krect
```

Use the matching file below for Ubuntu 26.04. Debian's `~rc.1` spelling allows a
normal upgrade to the final 0.4.0 release. Enable KRect and use two disposable
windows to try half placement, candidate selection, Esc dismissal and restoration.

### Validation and limits

- **101 automated tests:** 73 Node and 28 Python, including Debian RC-to-final ordering.
- **Four live Plasma 5.27/X11 scenarios:** click placement/focus/both restores, Enter selection, Esc dismissal and outside-click dismissal.
- Korean/English UI construction and nine chooser/snap-bar tests passed on Ubuntu 26.04 / Qt 6.10.2.
- **Live Plasma 6/Wayland, mixed scaling and monitor hotplug remain unverified.** Container Qt checks do not establish desktop behavior.
