# KRect 0.4.0-rc.2

**프리릴리즈 / Prerelease** · 안정판 / Stable: [0.3.1](https://github.com/ziwon/KRect/releases/tag/v0.3.1)

## 한국어

가상 데스크톱별로 창 배치를 저장하고 필요할 때 복원할 수 있습니다.

### 새 기능

- **작업 공간 프리셋:** 데스크톱 하나 또는 전체의 앱·창 위치·크기·모니터와 읽을 수 있는 최대화·최소화 상태를 저장합니다. 이름을 붙이고 개별 또는 전체 복원을 실행할 수 있습니다.
- **시작 시 복원:** 프리셋별로 설정하며, 늦게 열리는 창을 최대 30초 기다립니다. 이미 처리한 창은 반복해서 움직이지 않습니다. 로그인 때도 복원하려면 환경설정의 로그인 시 실행을 켜세요.
- **미실행 앱 열기:** 기본값은 꺼짐입니다. 켜면 설치된 앱 항목으로 프로그램마다 한 번 실행합니다. 문서·브라우저 탭·로그인은 각 앱의 세션 복원을 따릅니다.
- **두 창 교환·되돌리기:** 같은 모니터·데스크톱의 두 창 위치와 크기를 바꿉니다. 기본 단축키는 없으며 실제 창 교환 검증은 남아 있는 실험적 기능입니다.

프리셋은 `~/.config/krect/workspaces.json`에 사용자 전용 권한으로 저장됩니다. 같은 앱의 여러 창을 구별할 수 없으면 임의로 옮기지 않습니다. 삭제된 데스크톱·다른 활동은 건너뛰며, 저장한 모니터가 없으면 현재 모니터에 맞춰 배치합니다. 복원 중단 시 이미 완료한 배치는 유지합니다.

### 설치와 사용

기존 KRect를 트레이에서 완전히 종료한 뒤 설치하고 다시 실행하세요. Ubuntu 24.04 기준:

```bash
sudo apt install ./krect_0.4.0-rc.2-1ubuntu24.04_all.deb
krect
```

Ubuntu 26.04는 아래 표의 해당 파일을 사용하세요. 다운로드 파일명은 `-rc.2`, 내부 Debian 버전은 `~rc.2`를 사용해 RC1과 정식 버전 사이의 업그레이드 순서를 유지합니다.

**작업 공간 → 모든 데스크톱 배치 저장**으로 시작하고, 데스크톱별 이름·시작 시 복원 옵션을 저장하세요. 새 프리셋의 시작 시 복원은 기본으로 켜져 있습니다. 창 추천과 About 화면 등 RC1 기능도 포함합니다.

### 검증과 제한

- 자동 테스트 **136개**: Node 91개, Python 45개. Qt 5와 Ubuntu 26.04 / Qt 6의 화면 생성·컨트롤러 검사도 통과했습니다.
- **Plasma 5.27/X11 실기 복원 3개 시나리오:** 가상 데스크톱·듀얼 모니터 환경에서 수동 복원, 시작 시 복원 콜백, 앱·제목 기반 창 매칭을 검증했습니다.
- 실제 위치·크기·데스크톱·모니터·최대화·최소화가 복원됐고 현재 데스크톱·포커스와 다른 창 상태는 유지됐습니다. 테스트 창·스크립트는 정리했으며 기존 앱은 교체하지 않았습니다.
- **실제 재로그인, 새 앱 실행·미실행 앱 자동 실행, 창 교환, Plasma 6/Wayland, 혼합 배율·모니터 연결 변경은 미검증입니다.** 시작 콜백 검사는 현재 로그인 세션 안에서 수행했습니다.
- 전체 화면·대화상자·고정 크기·사용자 지정 타일·공유 데스크톱 창은 저장에서 제외합니다. 엔진 연결 전에 최대화한 일부 Plasma 5 창은 좌표·크기 복원이 우선됩니다.

## English

Save window layouts for each virtual desktop and restore them when needed.

### New features

- **Workspace presets:** capture one or all desktops, including app identity, window frames, monitors and available maximize/minimize state. Name presets and restore them individually or together.
- **Startup restoration:** enable it per preset, with up to 30 seconds of waiting for late windows. Each matched window is handled once. Enable login startup in Preferences to restore after login.
- **Launch missing applications:** off by default. When enabled, installed desktop entries launch each missing app once. Documents, browser tabs and authentication remain the app's own session responsibility.
- **Window swap and pair undo:** exchange the frames of two windows on the same monitor and desktop. There are no default shortcuts. This feature is experimental; native swap validation remains pending.

Presets are stored with user-only permissions in `~/.config/krect/workspaces.json`. Ambiguous windows are left in place. Missing desktops and other activities are skipped; unavailable monitors fall back to the window's current monitor. Stopping restoration keeps completed placements.

### Install and try

Quit KRect through its tray menu, install the package and launch it again. For Ubuntu 24.04:

```bash
sudo apt install ./krect_0.4.0-rc.2-1ubuntu24.04_all.deb
krect
```

Use the matching file below for Ubuntu 26.04. Asset names use `-rc.2`; the internal Debian version uses `~rc.2` to preserve upgrade ordering between RC1 and the final release.

Start with **Workspaces → Save all desktop layouts**, then save names and startup options per desktop. Startup restoration defaults to enabled for new presets. RC1's second-window suggestions and About dialog are also included.

### Validation and limits

- **136 automated tests:** 91 Node and 45 Python. UI construction/controller checks passed with Qt 5 and Ubuntu 26.04 / Qt 6.
- **Three live Plasma 5.27/X11 restoration scenarios:** manual restore, the scheduled startup callback and app/title matching across virtual desktops and dual monitors.
- Actual frames, desktops, monitors and maximize/minimize state were restored. The current desktop, focus and other windows' state remained unchanged. Test windows/scripts were cleaned up; the existing app was retained.
- **Actual relogin, new app processes, optional app launching, native swaps, Plasma 6/Wayland, mixed scaling and hotplug remain unverified.** The startup callback test ran within the existing login session.
- Fullscreen, dialog, fixed-size, custom-tiled and shared-desktop windows are excluded. Some Plasma 5 windows maximized before engine startup fall back to restoring their frame.
