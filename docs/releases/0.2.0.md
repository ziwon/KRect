# KRect 0.2.0

## 한국어

**이제 KRect를 앱 실행기에서 찾아 열고, 버튼이나 트레이로 창을 배치할 수 있습니다.**
기존 KWin 엔진에 네이티브 Qt 앱, 모니터 미리보기와 단축키 편집기를 더했습니다.

### 새 기능

- **18개 창 배치 동작**을 앱 버튼, 트레이 메뉴, 전역 단축키로 실행합니다.
- 실제 모니터 위치와 작업 창을 미리 봅니다. 세로 모니터에서는 3분할을 위아래로 배치합니다.
- 앱에서 KDE 단축키를 편집하고 충돌을 확인합니다. 창 간격, 제외 앱과 로그인 시 실행도 설정할 수 있습니다.
- 마지막으로 선택한 작업 창을 기억하며 KRect 자신의 창은 배치 대상에서 제외합니다.
- 한국어·영어 UI와 Ubuntu 24.04용 Qt 5, Ubuntu 26.04용 Qt 6 `.deb` 패키지를 제공합니다.

### 고친 점

- Plasma 5에서 관찰한 최대화 상태를 원래 배치와 함께 복원하도록 수정했습니다.
- 앱에서 저장한 설정이 실행 중인 KWin 엔진에 반영되도록 수정했습니다.

### 설치와 업데이트

아래 **Downloads / 다운로드**에서 Ubuntu 버전에 맞는 `.deb`를 내려받으세요.
다운로드한 폴더에서 실행합니다. 26.04에서는 해당 파일명으로 바꾸세요.

```bash
sudo apt install ./krect_0.2.0-1ubuntu24.04_all.deb
```

앱 실행기에서 **KRect**를 검색하고 **KRect 켜기**를 누르세요.
소스로 설치한 사용자 복사본이 있으면 앱을 종료하고 소스의 `bash uninstall.sh`로 제거한 뒤 설치하세요.
0.1.0 시스템 패키지만 설치했다면 위 명령으로 업그레이드할 수 있습니다.

### 검증 범위

자동 테스트 **63개**, Plasma 5.27 / X11에서 실제 앱 동작 **14개**를 통과했습니다.
Ubuntu 24.04·26.04 컨테이너에서 패키지 설치·제거와 Qt 5/6 화면 생성을 확인했습니다.
Plasma 6 / Wayland 실기, 혼합 배율, 물리 단축키 입력과 로그인 자동 시작은 추가 검증이 필요합니다.
마우스 드래그 스냅과 사용자 지정 배치 프리셋은 포함하지 않습니다.
[자세한 검증 기록](https://github.com/ziwon/KRect/blob/v0.2.0/docs/VALIDATION.md)

## English

**Find KRect in your application launcher and arrange windows with buttons or the tray menu.**
This release adds a native Qt app, a monitor preview, and a shortcut editor to the existing KWin engine.

### New

- Run **18 window actions** through app buttons, the tray menu, or global shortcuts.
- Preview your actual monitor arrangement and selected work window. Thirds stack vertically on portrait displays.
- Edit KDE shortcuts and check for conflicts in the app. Configure window gaps, excluded apps, and login autostart.
- Keep the last selected work window as the target, excluding KRect's own window.
- Korean and English UI, with Qt 5 `.deb` packages for Ubuntu 24.04 and Qt 6 packages for Ubuntu 26.04.

### Fixed

- Restore maximization states observed on Plasma 5 alongside the original window placement.
- Apply preferences saved in the app to the running KWin engine.

### Install and update

Choose the `.deb` for your Ubuntu version under **Downloads / 다운로드** below.
Run this in your download folder. On 26.04, substitute the matching filename.

```bash
sudo apt install ./krect_0.2.0-1ubuntu24.04_all.deb
```

Find **KRect** in the application launcher and click **Enable KRect**.
If you have a user installation from source, quit the app and remove that copy with `bash uninstall.sh` from its source folder first.
An existing 0.1.0 system package can be upgraded directly with the command above.

### Validation

Passed **63 automated tests** and **14 live app checks** on Plasma 5.27 / X11.
Package installation, removal, and Qt 5/6 UI construction were checked in Ubuntu 24.04 and 26.04 containers.
Live Plasma 6 / Wayland sessions, mixed scaling, physical shortcut input, and login autostart still need validation.
Mouse-drag snapping and custom layout presets are not included.
[Detailed validation record](https://github.com/ziwon/KRect/blob/v0.2.0/docs/VALIDATION.md)
