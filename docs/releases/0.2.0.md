# KRect 0.2.0

KRect가 앱 실행기에서 검색하고 실행할 수 있는 Rectangle 스타일 KDE 데스크톱 앱으로 확장됐습니다.
KWin 엔진과 함께 전용 Qt 창, 시스템 트레이, 배치 미리보기와 단축키 편집기를 제공합니다.

## 주요 변경

- 18개 창 배치 동작을 앱 버튼, 트레이 메뉴, 전역 단축키로 실행합니다.
- 실제 듀얼 모니터 위치와 작업 창을 미리 보고, 세로 모니터에서는 3분할을 위아래로 배치합니다.
- 앱에서 KDE 단축키를 편집하고 충돌을 확인합니다. 간격, 제외 앱, 로그인 시 실행도 설정할 수 있습니다.
- 마지막으로 선택한 작업 창을 기억하며 KRect 자신의 창은 배치 대상에서 제외합니다.
- Plasma 5의 최대화 상태 복원과 실행 중 KWin에 설정 변경을 반영하는 동작을 수정했습니다.
- Ubuntu 24.04에는 Qt 5, Ubuntu 26.04에는 Qt 6 의존성을 포함한 `.deb`를 제공합니다.

## 설치

| 환경 | 설치 파일 |
| --- | --- |
| Ubuntu 24.04 / Plasma 5.27 | `krect_0.2.0-1ubuntu24.04_all.deb` |
| Ubuntu 26.04 / Plasma 6 | `krect_0.2.0-1ubuntu26.04_all.deb` |

```bash
sudo apt install ./krect_0.2.0-1ubuntu24.04_all.deb
```

설치 후 앱 실행기에서 **KRect**를 검색하고 **Enable KRect**를 누르세요.
기존 사용자 범위 설치가 있으면 앱을 종료하고 소스의 `bash uninstall.sh`로 제거한 뒤
`.deb`를 설치하세요. 사용자 범위 스크립트가 시스템 설치보다 우선하기 때문입니다.
0.1.0 시스템 패키지만 설치했다면 위 명령으로 업그레이드할 수 있습니다.

`.kwinscript`는 KWin 엔진만 포함하고, `.zip`은 데스크톱 앱을 포함한 전체 소스입니다.
함께 제공하는 `SHA256SUMS`로 다운로드 파일을 확인할 수 있습니다.

## 검증 범위와 남은 부분

자동 테스트 63개와 Plasma 5.27 / X11에서 새 앱의 실제 동작 검증 14개를 통과했습니다.
Ubuntu 24.04·26.04 컨테이너에서 실제 패키지 설치·제거와 Qt 5/6 화면 생성을 확인했습니다.

Plasma 6 / Wayland의 실제 데스크톱 동작, 혼합 배율, 물리 단축키 입력과 로그인 자동 시작은
추가 검증이 필요합니다. 마우스 드래그 스냅과 사용자 지정 배치 프리셋은 포함하지 않습니다.
자세한 결과는 [검증 기록](https://github.com/ziwon/KRect/blob/v0.2.0/docs/VALIDATION.md)에 있습니다.
