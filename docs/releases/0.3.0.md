# KRect 0.3.0

## 한국어

**창을 화면 상단 중앙으로 끌고, 원하는 영역에 놓으세요.**
배치 막대에서 위치를 미리 보고 마우스를 놓으면 창이 배치됩니다.

### 새 기능

- **상단 드래그 배치**: 좌우·상하 2분할, 3분할, ⅔+⅓, ⅓+⅔, 4분할을 선택합니다.
- 실제 모니터의 작업 영역과 창 간격을 적용합니다. 세로 모니터에서는 ⅓·⅔ 구성이 위아래로 바뀝니다.
- 막대를 벗어나면 일반 드래그를 계속하고, `Esc`로 취소합니다. 복원 단축키는 드래그 시작 전 위치로 돌아갑니다.
- 배치 막대가 작업 창의 포커스를 빼앗지 않습니다. 환경설정에서 기능을 끌 수 있습니다.
- 한국어·영어·일본어 [웹사이트](https://krect.pages.dev/)에 실제 배치 막대 캡처, 사용법과 버전별 무료 다운로드를 추가했습니다.

### 고친 점

- Ubuntu 26.04 패키지에 Qt 6 SVG 플러그인 의존성을 명시해 앱 아이콘을 표시합니다.
- 새 앱을 실행하면 이전 KWin 엔진을 감지하고 다시 연결합니다.

### 설치와 사용

업데이트 전 트레이 메뉴에서 **KRect 종료**를 선택하세요. 아래에서 Ubuntu 버전에 맞는 `.deb`를 받아 다운로드한 폴더에서 실행합니다.

```bash
sudo apt install ./krect_0.3.0-1ubuntu24.04_all.deb
```

26.04에서는 해당 파일명으로 바꾸세요. 앱을 다시 열고 **KRect 켜기**를 누른 뒤 트레이에서 실행해 두세요.
창의 제목 표시줄을 잡고 **모니터 상단 중앙 → 막대의 원하는 영역**으로 이동한 뒤 놓습니다.
드래그 배치에는 데스크톱 앱이 필요합니다. `.kwinscript`만 설치하면 기존 단축키·창 메뉴를 사용할 수 있습니다.
소스 사용자 설치가 있다면 앱을 종료하고 기존 소스의 `bash uninstall.sh`로 제거한 뒤 `.deb`를 설치하세요.

### 검증 범위

자동 테스트 **80개**와 Plasma 5.27 / X11 듀얼 모니터에서 **드래그 실기 5개 시나리오**를 통과했습니다.
정확한 간격, 포커스 유지, 복원, 일반·최대화 창의 Esc 취소, 막대 이탈과 세로 화면 전환을 확인했습니다.
Qt 5/6 UI 생성과 Ubuntu 24.04·26.04 패키지는 자동 검증합니다.
**Plasma 6 / Wayland 실기, 혼합 배율, 드래그 중 모니터 분리와 앱별 크기 제한은 추가 검증이 필요합니다.**
최대화 버튼 호버와 사용자 지정 배치 프리셋은 포함하지 않습니다.
[자세한 검증 기록](https://github.com/ziwon/KRect/blob/v0.3.0/docs/VALIDATION.md)

## English

**Drag a window to the top center of a display, then drop it into a region.**
Preview the destination on the snap bar and release to place the window.

### New

- **Top snap bar** with horizontal and vertical halves, thirds, asymmetric thirds, and quarters.
- Uses each display's work area and your configured gaps. Thirds and two thirds stack vertically on portrait monitors.
- Leave the bar to continue dragging, press `Esc` to cancel, or use the restore shortcut to return to the position before the drag.
- The bar preserves focus on your work window. Disable it in Preferences if desired.
- A Korean, English, and Japanese [website](https://krect.pages.dev/en/) with real snap bar captures, instructions, and free downloads for each Ubuntu version.

### Fixed

- Explicit Qt 6 SVG plugin dependency for application icons in the Ubuntu 26.04 package.
- The new app detects an older KWin engine and reconnects it.

### Install and use

Before updating, choose **Quit KRect** from the tray. Download the `.deb` for your Ubuntu version below and run this in its folder:

```bash
sudo apt install ./krect_0.3.0-1ubuntu24.04_all.deb
```

On 26.04, substitute the matching filename. Reopen the app, click **Enable KRect**, and keep it running in the tray.
Drag a window's title bar to the **top center of a display**, move into a region on the bar, and release.
Drag layouts require the desktop app. The `.kwinscript` alone provides the existing shortcuts and window menu.
If you have a user installation from source, quit the app and remove that copy with `bash uninstall.sh` from its source folder before installing the `.deb`.

### Validation

Passed **80 automated tests** and **5 live drag scenarios** on a Plasma 5.27 / X11 dual-monitor desktop.
Checks covered exact gaps, preserved focus, restore, Esc from normal and maximized windows, leaving the bar, and portrait transfer.
Qt 5/6 UI construction and Ubuntu 24.04/26.04 packages are checked automatically.
**Live Plasma 6 / Wayland, mixed scaling, unplugging a display during a drag, and app-specific size constraints still need validation.**
Maximize-button hover and custom layout presets are not included.
[Detailed validation record](https://github.com/ziwon/KRect/blob/v0.3.0/docs/VALIDATION.md)
